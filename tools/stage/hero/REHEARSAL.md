Assumptions:
- 终端里的字是中文：插件本身就用中文跑；英文页上怎么办还没定（英文页现在也挂着这份中文演示）。
- Claude Code 的转录记号用 `●` 和 `⎿`，待办用勾和小方框，等宽字体；没有照搬 Claude Code 的橙色和吉祥物，颜色用官网的「清水」。
- 门禁拦下不用红色（官网的规矩），用反白的一小块。

Unresolved:
- 流畅度：录的时候显卡被 Blender 的 4K 渲染占满，覆盖率是 `inconclusive`（采样间隔超了），官网上水面的帧率看门狗也因此退成了静态。要等渲染结束再量。
- 官网里中文字体是按文案裁的子集，演示里的字没进文案，缺的字会落到系统字体；正式接入时要把演示的字放进 `src/copy/` 再重裁。
- 打包后的样式带了整套套件的 CSS（83 KB，压缩后 16 KB），可以只引用到用到的部件。

Not checked:
- Safari、Firefox；真手机上的触摸和性能；屏幕阅读器（演示整块 `aria-hidden`）。
- 比 16:9 更扁、或 2 倍放大封顶以后的超宽屏。

## 2026-11-22：正式接入官网、首屏改版式

上面是在 Stageshow 的预览里排练时的记录。接进官网以后改了这些：

- 文案挪到官网的 `src/copy/hero-demo.json`，页面从 `data-demo-copy` 传进来；演示的字进了中文字体的子集（上面 Unresolved 第二条已解决）。
- 只引用用到的部件，套件只拷了这些文件进 `../kit/`（上面 Unresolved 第三条已解决）。
- 设计尺寸不再固定 720 × 540：官网按留给演示的地方定（`../size.js`，字放大到 1.45 倍为止，多出来的地方让终端变宽、变高）。垫在上面跑完的那几趟从两趟加到三趟：高屏上终端很高，两趟垫不满时顶上会露空、复位也看得见。
- 不再出画：窗口铺满舞台（`inset: 0`），舞台不裁切，阴影画到外面；官网让窗口左右对齐页面内容区。原来照「从一条边出画」的规矩往右出画，用户看了问「为什么就是要靠右贴边」：这个页面有居中的内容区，出画的窗口和页头对不齐。键帽挪进输入框的右端。
- 终端的面加了一层静止的渐变：光从左上来，顶边一道细高光。
- 量过：Chromium、WebKit、Firefox 里挂上前后版式不动，终端左右对齐内容区，宽屏和高屏版式里整个终端都在首屏以内（官网 `browser-check.js` 的 `hero-demo`）。

还没看的：真手机上的触摸和性能；弱一点的显卡上终端放得很大时（高屏版式，舞台放大 1.45 倍、1200 宽上千高）的帧率。
