# 视觉方向

2026-11-20 定。读代码推不出来的选择和理由记在这里；色值、字号的具体数以 `src/styles/tokens.css` 为准。

## 一句话

水是软的，闸是硬的。会动、带渐变和弧线的只有水和闸室；字、标尺、按钮一律规矩、精确。

## 从哪来

产品名就是船闸。船闸这个东西自己带着一套图形：一级一级的闸室、闸门之间的缝、水位、闸墙上刻着数字的水尺。图标「梯级」已经用了前两样（三片、两道缝）。官网把它接着画下去，不另找比喻。

- **闸室**：竖着的长片，上下两端是圆弧，就是图标那三片的画法。过闸一节把三片接成八片，一片比一片高。
- **闸缝**：片与片之间 14 个单位宽的缝（图标的尺寸）。它是全页唯一的分隔图形：节与节之间、按钮里的细节、闯闸演示里关上的那道门。
- **水**：渐变从上到下，颜色取图标深浅两版的三档。首屏背景是一段着色器画的水下光影。
- **水尺**：过闸那张图左边的一根刻度尺，标着八级，浮标跟着船停在当前这一级。它代替了常见的进度条。手机上只留刻度，不显示数字。（原来想让它贯穿全页、当版面的脊；做出来只在过闸里有意义，就只放在那里。）

## 过闸怎么演

- 八个闸室一直都在画面里，不做镜头平移：一眼看得见整段梯级，水一室一室注满，船一级一级升上去。左边是当前这一段的说明，下面是一路落下来的产物。
- 每一拍四个动作，顺序照真的船闸：这一室放水到和下游齐平、船开进来、身后的闸门关上、水位升一级。
- 实现那一段的闸室比别的宽，里面分五道，对应五个并行的角色。
- 收尾不做「底色慢慢从深混到浅」：中间那一段是脏的灰色，字也看不清。改成水面从上往下退，同一张图在原地从深色版换成浅色版（就是图标的两版配色），页头在水面经过它的那一刻一下子换色。
- 手机上图在上、字在下，图还是横着一级比一级高，不改成竖排：横着才认得出是图标那三片接出来的。

## 配色

全部出自图标的两版配色，不加新的色相。

| 名字 | 色值 | 用在哪 |
| --- | --- | --- |
| 闸底 | `#08323F` | 深色段的底（暗端） |
| 深水 | `#11606A` | 深色段的底（亮端） |
| 水光 | `#7FE7D6` | 深色段的强调、光 |
| 浅水 | `#4FD0BB`、`#D3F6EC` | 深色段的水 |
| 纸 | `#F8F4EB`、`#EAE3D5` | 浅色段的底 |
| 墨 | `#13212B` | 浅色段的字 |
| 蓝 | `#17507C`、`#226F86`、`#23877E` | 浅色段的强调和水 |

浅色段是暖白底，容易滑向「暖白底加衬线大标题加陶土色」那种常见的生成稿。所以：不用衬线，强调色只用蓝青，不出现任何橙、红、棕。

## 字

一个家族，中英同一套：IBM Plex（OFL）。

- 正文和标题：IBM Plex Sans；中文用 IBM Plex Sans SC。中文字体按文案里实际用到的字裁成子集，自托管。
- 水尺和阶段编号的数字：IBM Plex Sans Condensed。闸墙上的水尺就是又高又窄的数字。
- 命令和文件名：IBM Plex Mono。只用在真的是代码的地方，不拿等宽字当装饰标签。

为什么是它：Plex 是为「人和机器」画的，笔画理性、细节硬朗，和软的水形成对照；它有简体中文版，中英两页的气质能一致；等宽和窄体是同一家族，不用再配。没选 Inter、Geist、Space Grotesk 这些，是因为它们是开发工具官网的默认选择。

设计文档原来写的是「中文用系统字体」。改成自托管子集的理由：Windows 上的系统中文字体（微软雅黑）在大字号下显得旧，而用户自己就在 Windows 上看。代价是多两百 KB 左右的字体；加载不出来时回落到系统字体。文案改了以后要重新裁子集，见仓库 `CLAUDE.md`。

字号按经典的排版阶梯走：14、16、18、21、24、36、48、60、72。标题不用全大写，不加字距。

## 版式

- 左对齐，靠着水尺这根脊。不做居中的大标题。
- 正文一行不超过 40 个汉字或 75 个西文字符。
- 不把内容切成一模一样的圆角卡片。闯闸是一块嵌进浅色段的深色面板；团队是一棵树；边界和安装是普通的列表和代码块。
- 圆角只有三档：小（6）用在代码块和小控件，中（14，就是闸缝的宽度）用在面板，胶囊用在按钮。闸室两端的弧是真的圆弧，不是圆角。

## 动效

水慢，闸快。

- 水位升降：600 到 1200 毫秒，先快后慢地停住，没有回弹。
- 闸门关上：280 到 360 毫秒，带一点过冲，要有分量。
- 一直在动的只有首屏的水面，而且慢。没有呼吸灯，没有悬停时到处都动的卡片。
- 不给每一节加「淡入上滑」的入场。有编排的动效只花在三处：首屏加载、过闸、闯闸里访客自己点的那一下。

## 不要的

和设计文档的红线一致：紫色渐变、渐变字、玻璃光球、emoji 当图标、「New」徽章、全大写加宽字距的小标签、呼吸灯、近黑底加荧光色的扁平硬边。另外不用：用中点连起来的元信息串、链接文字后面加箭头、每个标题上面再加一行小标签。
